# SnailyCAD Admin Tools

Easy tools to fix common SnailyCAD problems.  

**SnailyCAD** is a police/EMS dispatch system used in FiveM, GTA roleplay servers, and other gaming communities.

---

## 🚨 Problems This Fixes

### 👤 User Problems
- Forgot password → Reset it  
- Can’t log in because Discord broke → Unlink their Discord  
- Switched Discord accounts → Remove old Discord, link new one  
- See all users → List all registered users  

### 🔑 Login Problems
- Force Discord only → Turn off regular passwords  
- Discord login broken → Turn on password login  
- Want Steam login → Turn on Steam authentication  
- Disable whitelist → Let everyone join  

### 🛠️ Server Maintenance
- Database is slow → Clean and optimize it  
- See who’s online → Show active users  
- Check database health → Run health checks

## 📖 How to Use

If you want to run step by step, follow the doc here:  
👉 [https://recover.snailycad.co.uk/](https://recover.snailycad.co.uk/)

### 🖥️ Windows
1. Open **Command Prompt**  
2. Run one of these commands to download the recovery tool:

   Using **curl**:
   ```cmd
   curl -L https://raw.githubusercontent.com/EWANZO101/newdocs/main/caddownloads/recover.bat -o recover.bat



2. Double-click it  
3. Enter your database info  
4. Pick what you want to fix  

### 💻 Mac/Linux
1. Download the script:  
   ```bash
   wget https://raw.githubusercontent.com/EWANZO101/newdocs/main/caddownloads/full-snailycad-recovery.sh -O full-snailycad-recovery.sh

    Make it executable and run:

    chmod +x full-snailycad-recovery.sh
    ./full-snailycad-recovery.sh

    Enter your database info

    Pick what you want to fix

⚙️ Options
1. Show All Users

See all accounts (username, ID, Discord linked or not).
2. Unlink Discord Account

Remove Discord from a user. Use if login breaks or they changed Discord accounts.
3. Turn Off Whitelist

Lets anyone join.
⚠️ This affects the entire server.
4. Change Login Methods

    ALLOW_REGULAR_LOGIN → ON = password login works. OFF = must use Discord/Steam.

    STEAM_OAUTH → ON = Steam login allowed. OFF = no Steam login.

    DISCORD_AUTH → ON = Discord login works. OFF = no Discord login.

Common setups:

    Force Discord only → OFF regular login, ON Discord

    Emergency login → ON regular login

    Add Steam → ON Steam OAuth

5. Reset Password

Pick a user from the list and set a new password.
6. Server Maintenance

    Vacuum = cleanup deleted data

    Update Stats = speed up queries

    Check Health = see if database is broken

    Show Size = check database size

    Show Connections = see who’s online

🆘 Emergency Fixes

    Run tool

    Run tool

    Option 2 → Unlink Discord

    Enter Discord IDs

User can’t log in (forgot password + Discord broken)

    Option 2 → Unlink Discord

    Option 5 → Reset password

    Give new password

Need to let everyone in now

    Run tool

    Option 3 → Turn off whitelist

    Confirm

🔑 What You Need

Find database info in your .env file:

    Database name → DATABASE_URL or POSTGRES_DB

    Username → DATABASE_URL or POSTGRES_USER

    Password → DATABASE_URL or POSTGRES_PASSWORD

    Host/server → DATABASE_URL or POSTGRES_HOST

    Port → DATABASE_URL or POSTGRES_PORT

Example:

username = postgres
password = yourpassword
host = localhost
port = 5432
database = snaily-cad

🐞 Troubleshooting
❌ Connection refused

    Check PostgreSQL is running

    Check username/password

    Try localhost as server

🔒 Permission denied

    Use postgres superuser

    Or ask a database admin

📌 Notes

    Always back up your database first

    Test with one user before big changes

    These tools edit your database directly

    Never share your database password
